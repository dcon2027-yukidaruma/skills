# skills


DCON2027チーム向けに作成した Muse の Skills 置き場。


- `dcon_minutes` — Drive上の会議音声を自宅サーバーのWhisperで文字起こしし、さくらのAI Engineで議事録テンプレに沿って要約して、Driveの01_議事録へ保存する

- `chouseisan_reminder` — 調整さんの日程調整で未回答のメンバーを定期確認し、Discordでメンションリマインドする

- `email_rules` — 外部メール（依頼・問い合わせ）の運用ルール。送信前の文面確認、教員CC、共有フォルダへの集約と管理シートへの記録、自分で決めない事項を定める


各フォルダの `SKILL.md` が手順本体、`skill.yaml` がメタデータ。
